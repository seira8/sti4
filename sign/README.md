# SIGN STAMP（サインスタンプ）

画像に自分のサインを入れるための、ブラウザだけで動くツールです。
サインは一度登録すればブラウザに保存されるので、毎回登録し直す必要はありません。

## 使い方

1. **サインを登録**：画像から（紙に書いて撮った写真でもOK、白背景は自動で透明に）／手書き／文字＋フォント
2. **画像を選ぶ**：複数枚まとめてドロップ・貼り付けOK
3. **位置と見た目を調整**：9か所の位置 or ドラッグで自由配置、大きさ・余白・濃さ・色・影
4. **保存**：原寸のまま保存。複数枚はZIPでまとめて保存

## プライバシー

画像もサインも、すべて自分のブラウザの中だけで処理されます。どこかのサーバーに送られることはありません。
登録したサインはそのブラウザの localStorage に保存されます（別の端末・別のブラウザには引き継がれません）。

## 公開方法（GitHub Pages）

1. このリポジトリに `index.html` を置く
2. Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で使えるようになります

## 使っているもの

- [JSZip](https://stuk.github.io/jszip/)（ZIP保存）— cdnjs から読み込み
- Google Fonts（Inter Tight, Zen Kaku Gothic New, 各種手書きフォント）
